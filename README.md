# 公三备考打卡 · PETS-3

公共英语三级（PETS-3）专属备考打卡 App：单词、语法、阅读、听力、作文与学习监督全部在一个静态网页内完成，可添加到手机桌面，离线可用。

## 功能

| 模块 | 内容 |
|------|------|
| 今日打卡 | 五项任务、学习计时、连续天数 |
| 单词 | 120 个公三高频词 · 闪卡 + 自测 |
| 语法 | 8 个考点专题 · 要点 + 刷题 |
| 阅读 | 6 篇真题风格短文理解 |
| 听力 | 8 则训练 · 系统语音朗读 + 作答 |
| 作文 | 8 题 · 在线写作提交 + 范文对照 |
| 进度 | 时长柱状图、打卡曲线、模块完成度、错题本 |
| 我的 | 目标设置、提醒、导出备份、重置进度 |

## 版本更新与重置进度

1. 修改代码后，把 `js/storage.js` 顶部的 `APP_VERSION`（例如 `2.0.0` → `2.1.0`）改一下。
2. 同步把 `sw.js` 里的 `CACHE_NAME` 改成新值（例如 `pets3-prep-v3`），方便手机刷新缓存。
3. `git push` 到 GitHub Pages 分支。
4. 用户打开 App 时若检测到版本号变化，会弹出：**重置进度** 或 **保留进度**。

也可在「我的」里随时手动「重置全部学习进度」。

## 本地预览

```bash
python -m http.server 8080
```

访问 `http://localhost:8080`。

## GitHub Pages

Settings → Pages → Deploy from branch → `main` / `/ (root)`  
地址：`https://<用户名>.github.io/<仓库名>/`

手机：Safari「添加到主屏幕」或 Chrome「安装应用」。

## 说明

- 听力使用浏览器 `speechSynthesis` 英文朗读，无外链音频，完全离线。
- 学习数据保存在本机 `localStorage`，不上传服务器。
- 内容贴合公三大纲方向，便于日常闭环备考；可按同样数据结构自行扩充题库。
